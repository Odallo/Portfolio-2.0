# Odallo Eugine — Portfolio

Personal portfolio and services website built with Next.js, TypeScript, and Tailwind CSS.

## What's Inside

- **Hero** — introduction with terminal-inspired interaction
- **About** — background, values, and what I care about
- **Projects** — selected work: MiniRDBMS, Weather App, CLI Goal Tracker, Hotel Management System
- **Skills** — technologies and tools I use daily
- **Services** — pricing for starter websites, business sites, and e-commerce (KES pricing, M-Pesa ready)
- **Contact** — form with budget/timeline selectors, Web3Forms integration

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Web3Forms (contact form)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deploy to Vercel:

```bash
npx vercel
```

Or push to GitHub and connect your repo on [vercel.com](https://vercel.com).
